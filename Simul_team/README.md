# MCI_Experiment_Autonomation 사용 설명서 (v5.0)

## 사전준비

1. MCI conda 가상환경 설치

2. (MCI) 활성상태에서 패키지 설치 (pip install pandas numpy requests haversine pyyaml geopandas shapely gymnasium scipy openpyxl)

3. scenarios 폴더 안에 안전센터와 소방서.csv, 엑셀 결합 데이터.xlsx, ctprvn.shp, ctprvn.shx, ctprvn.dbf 반드시 존재해야 함.

4. 프로젝트 폴더에는 시뮬레이션 관련 파일들 존재해야 함.

5. 네이버 API 키 인지하고 있어야 함.

## 실행순서
1. 사전준비 다 마쳤으면 MCI_Experiment_Autonomation_v5.0.ps1 더블클릭

2. [📁 프로젝트 경로 설정] 프로젝트 경로 설정은 엔터 치면 현재 디렉토리로 인식하나 프로젝트 폴더의 위치를 C:\Users\사용자명에 위치하는 것이 좋음. 

3. [🐍 Conda 환경 탐지] "MCI 환경을 사용하시겠습니까?"에 y(Y) 누르면 자동으로 가상환경 실행되고 n(N) 누르면 로컬에 있는 가상환경 리스트 뜨고 선택 가능 

4. [🔑 Naver API 키 설정] 네이버 API Client ID/Client Secret 두 개 순차적으로 입력 후 환경변수에 저장 

5. [📦 Python 패키지 확인] 이후 과정에서 필수 요구사항(MCI 활성화, 설치된 패키지 확인) 자동으로 검사해주고 누락시에 피드백 뜸

6. [🎯 시뮬레이션 개수 설정] 생성할 시뮬레이션 개수를 입력하는데 10개까지 limit 걸어둠. 다만 단일좌표로 파라미터만 수정해서 실험할거면 1개씩 여러번 하는 것을 추천. 

7. [⚙️ 고급 옵션(병원선정/AMB/Patient)] 
queue_policy: hospital_info에서 queue_capa를 설정하는 옵션으로 디폴트는 0이지만 capa/2, capa/3, capa/4 또는 0.5, 0.333 등의 형식으로 설정 가능(소수점은 버림 처리)

util_by_tier: 병상수를 정하는 것으로 사용 가능한 병상수 = 전체 병상수 * (1 - util)이며 이때 util에 해당하는 값들이다. 상급종합병원, 종합병원, 그외 이렇게 세가지 종별코드로 적용되며 1주차 main_make_data.py에 적용된 보정계수(1-util) 0.344, 0.539를 적용하기 위해 util의 디폴트는 1:0.656,11:0.461,etc:0.461로 설정함.

buffer_ratio: 병원선정시 capa가 누적되는데 버퍼 비율에 따라 병원 후보군을 여유있게 확장 또는 타이트하게 확장 조절할 수 있는 파라미터로 디폴트는 1.5이다. 다만 후보군 확장은 euc(유클리드) 거리만 쓰므로 API 호출과는 관련 無 + 도심이나 병원 인프라 잘 구축된 지역에는 버퍼를 줄여보기/ 농촌이나 산간지역 같은 시골에서는 버퍼를 늘려보기
※ AMB 후보군 확장은 buffer_ratio가 아닌 make_csv_yaml_dynamic.py 내에 multiplier(=2)가 결정 

patient_info 파라미터 수정: Red 비율(기본=0.1), Yellow 비율(기본=0.3), Green 비율(기본=0.5), Black 비율(기본=0.1)

hospital.max_send_coeff (a,b): eff = a * capa(병상수) + b * queue_capa(병상대기행렬)의 식에서 a,b 값을 1,1 또는 1.5,1 이런식으로 입력해서 설정 가능

8. [📋 디폴트 파라미터 설정] 만약 위에서 생성할 시뮬레이션 개수를 2개 이상 했고 기존에 정해진 디폴트 파라미터로 일괄적으로 시나리오를 생성할거면 y를 눌러 진행하고 생성모드를 변경하고 싶으면 n을 눌러야 함. 당분간은 고정좌표 내에서 파라미터를 수정할 것이므로 이 단계에서 n을 눌러 다음 좌표 생성 모드로 진입해야 함.

## 실행결과 파일들..

시뮬레이션의 개수를 정하고 확정되는 순간에 실험ID가 생성되는데 형식은 exp_YYYYMMDD_HHMMSS로 만들어진다. scenarios폴더 내에 실험폴더가 생성되고 그 내에 좌표폴더가 생성되고 실험폴더 내에는 실험에 대한 요약 csv파일이 실험ID_summary.csv로 저장되며 
실험ID 순번	생성모드	생성유형	좌표정보	실제위도	실제경도	주소	도로명주소	시도	시군구	읍면동	리	시나리오생성_시작	시나리오생성_소요(초)	시뮬레이션_시작	시뮬레이션_소요(초)	실험_완료시간	좌표별_총소요(초)	성공여부	로그파일	환자수	max_send_coeff	구급차수	UAV수	구급차속도	UAV속도	시뮬레이션반복	랜덤시드
가 저장됨.

results폴더에는 main.py의 실행결과 각 Rule 조합별 Reward(보상값)와 PDR(예방가능사망률)의 평균, 표준편차, 95%신뢰구간이 기록되며 w.o.G(without Green) 지표도 기록됨.

experiment_logs폴더에는 시뮬레이션의 실행 중 생성되는 터미널의 텍스트 로그가 기록되는 txt가 저장된다.
