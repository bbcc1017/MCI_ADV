MCI 대시보드를 장비처럼 보이게

Streamlit 구조는 그대로 두고 CSS 주입만으로 도달 가능한 세 가지 방향. 각 시안은 실제 대시보드 화면 — 사이드바 / 탭 / KPI / 결과 테이블 — 을 그 스킨으로 그린 목업이다. 색만 바꾼 세 개가 아니라, 정보 배치 자체가 서로 다르다.

작업 범위

건드리는 파일은 두 개. src/vis_src/MCI_Streamlit.py:1427 의 CSS 블록과 .streamlit/config.toml 의 [theme]. Python 로직·데이터 경로·subprocess 호출부는 손대지 않는다.

Streamlit Community Cloud는 unsafe_allow_html=True 와 @import 웹폰트를 모두 허용한다. 세 시안 전부 배포된 상태에서 그대로 동작한다. 도메인은 *.streamlit.app 로 유지된다.

어느 쪽을 고르든 같이 들어가는 것

지금 MCI_Streamlit.py:1427 의 CSS 블록에 빠져 있는 부분이다. Streamlit 기본 크롬이 그대로 노출돼 있어서, 어떤 스킨을 씌워도 우상단 햄버거·Deploy 버튼·하단 워터마크 때문에 “Streamlit 앱”으로 읽힌다. 아래 블록이 그걸 제거하고, CSS를 4개 페이지가 공유하도록 한 파일로 뺀다. 

# src/vis_src/_theme.py — 새 파일. 4개 페이지가 전부 import.
# MCI_Streamlit.py / pages/Generate.py / pages/ResultsCompare.py
# / pages/BatchExperiment.py 각각 맨 위에서 inject_theme() 호출.

_CHROME = """
#MainMenu, header[data-testid="stHeader"], footer,
[data-testid="stToolbar"], [data-testid="stDecoration"],
[data-testid="stStatusWidget"] { display: none !important; }

[data-testid="stAppViewContainer"] > .main { padding-top: 0 !important; }
[data-testid="stSidebarNav"] { padding-top: 8px; }   /* 페이지 목록을 진짜 내비로 */
.block-container { padding-top: 1.6rem !important; max-width: 1400px; }
"""

.streamlit/config.toml 과 src/vis_src/.streamlit/config.toml 은 지금 내용이 갈라질 위험이 있는 수동 복제본이다. 선택한 팔레트로 두 파일 모두 갱신한다.
